# Session Management

How to run AI-assisted development sessions cleanly.

## The core principle

Each major session starts with curated context. Long-running chats or terminals accumulate state bloat that degrades quality. A fresh session with a handoff note beats an exhausted session with hidden assumptions.

## When to start a new session

Always start fresh for:

- a new sprint
- a new verification phase
- returning the next day
- after a major committed milestone
- after hitting a budget cap
- when the current session has become noisy or error-prone

## How to start a new session

1. Open your preferred runtime.
2. Start in the correct project directory.
3. Load the handoff note and the current spec.
4. Restate scope, rules, budget, and stop markers.

## How to end a session

Every session ends with a clean handoff, not a dangling state.

1. Write a handoff note.
2. Commit finished work in deliberate chunks.
3. Push when the work is ready to be preserved remotely.
4. Write any ADRs required by decisions made in the session.
5. Update the retro if a sprint or phase closed.
6. List outstanding items for the next session.
